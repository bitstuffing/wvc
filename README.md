# Web Video Caster

An open-source Android app for capturing media links from the web and casting them to Chromecast-compatible devices — without Google Play Services.

## Features

- Capture multimedia links while browsing.
- Cast to compatible devices without Google Play Services or GMSCore.
- Designed for AOSP, LineageOS, and other de-Googled Android systems.

Compatibility may vary by device and receiver. Add only combinations you have tested.

## Build

1. Clone the repository.
2. Open it in Android Studio, or build with the included Gradle wrapper.
